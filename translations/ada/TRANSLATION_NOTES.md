# Translation Notes — Dangme

**Status: DRAFT — NOT YET REVIEWED.** Translated by Claude (AI) on 5 Nov 2026 from the English files in https://github.com/neiltucker/JWLibrary, using the reviewed Ga tutorial as the layout guide. The translator is not a Dangme speaker. **Do not give these files to students until a fluent Dangme reader has corrected them.** Each Dangme file carries a visible draft notice for this reason; remove it after review (list in section 6).

## 1. Rules used

**Order for choosing a word (set by the project owner): JW.ORG > Ga translation > Internet.**
1. Dangme publications on JW.ORG and the Online Library (`wol.jw.org/ada/.../r217/lp-dg`), preferring the last 3–5 years.
2. Where JW.ORG has nothing, the reviewed Ga translation, adapted to Dangme spelling and grammar (for example Ga *mobail data* stays *mobail data*, Ga *okiibɔd* becomes *kiibɔd*).
3. The wider Internet. No Dangme wording in this draft comes from this level.

**Layout:** as close to `gaa.html` as possible, because the same teachers may use both. Section order, exercise numbers, timings, element IDs, CSS, scripts and PDF page counts match. The sentences are not converted from Ga; only the structure is shared.

**Differences from the Ga tutorial (all on purpose):**
| Difference | Why |
| :--- | :--- |
| Draft notice on the page, class outline, README and both PDFs | Ga's notice was removed only after Ga speakers validated it. Remove this one the same way. |
| **Largest Size** has no meaning in brackets (Ga has *Edalɛ*) | The Dangme help shows the English label only. |
| Times are written *hɛngm. 15* | The 2026 workbook writes "(Hɛngm. 10)". The full word was not found, so the abbreviation is used everywhere, and "one hour" is written *hɛngm. 60*. |
| Midweek meeting is the workbook's own name, *Si Himi Kɛ Sɔmɔmi Ní Tsumi Kpe*, not a literal "middle of the week" | JW.ORG level beats a Ga-style phrase. |
| PDF legal line on the Class Program also carries a short English version | The Dangme legal wording is unreviewed. |

**Exercise 2.3** uses a Bible chapter only, the same as every other language since 5 Nov 2026. The project owner confirmed that the Daily Text has no headphones/audio option, even in English, on Android and Windows. iPhone was not checked, but the wording is the same on all devices so the tutorials stay uniform.

## 2. How the sources were read — please keep in mind
JW.ORG pages were read through a web tool that returns a machine summary with short quotes, not the full page. The quoted Dangme phrases below came through that tool, and it sometimes guessed meanings wrongly. English meanings are therefore inferred. A reviewer should treat the source column as "where to look", not as proof of meaning.

These pages could not be loaded during this work (server errors or not reachable): the Online Library's Meetings page and several library category pages, and direct links to the Dangme versions of the articles cited in the Ga notes (for example *w23* March p. 32 and *w25* June p. 32, which mention JW Library). **Those articles are the best places to check first**, because Online Library document numbers appear to be shared across languages: take a Ga link from `translations/gaa/TRANSLATION_NOTES.md` and replace `gaa/wol/d/r121/lp-ga` with `ada/wol/d/r217/lp-dg`. (This pattern was seen but not tested, because such links were blocked here.)

### 3e. Own wording — no Dangme or Ga source to copy (please check first)
* **Silence the sound:** *Ha gbi ɔ nɛ kpa (amlɔ nɛ ɔ)*. *Ha nɛ … nɛ* follows titles such as *Ha Nɛ Wa Hemi Kɛ Yemi ɔ Mi Nɛ Wa*. *kpa* ("stop") is inferred from the title *Ke Wa Suɔlɔ Ko Kpa Yehowa Sɔmɔmi* (*w21*); that page would not load, so the meaning is from the translator's memory of the English title. *gbi* for "sound" is inferred from its use for "voice/language".
* **Press and hold a button:** *Moo nyɛ … nɔ nɛ o kɛ o nine nɛ pi nɔ* (built from the help's highlighting wording).
* **Waste mobile data:** *konɛ o mobail data a ko puɛ* (*puɛ* from *be puɛmi*, *lff* Lesson 1).
* **Non-commercial:** *nɛ pi jua yemi ní tsumi*. Not found in the Dangme Terms of Use by the tool.
* **Legal negatives:** *a pee we, a ngmɛ we blɔ kaa a pee, a hyɛ we nɔ, a wo we he sika, nɛ a kplɛɛ we nɔ*. The exact meaning matters; the English original stays under it.
* **Words from memory or pattern, not traced to a source:** *loko* (before), *mwɔnɛ* (today), *ekohu* (again), *amlɔ nɛ ɔ* used for "at once" (the source use is "now"), *blɛuu* (slowly, quietly), *kulaa* (completely), *saminya* (well), *jã nɔuu* (the same way), *momo* (already; seen in the help), *nimeli* (older people), *akɛnɛ* (because), *agbo* (door; also "big"), *he hia* (is needed), *klashi*, *Vɛshɔn*, *faa* (clear).
* **Side of the device:** *left* and *right* are left in English because no Dangme words were found.
* **Grammar in general:** determiners (*ɔ*, *a*, *ɔmɛ*), command forms (*Moo nyɛ*, *Hyɛ*, *Bli*, *Ngɔɔ*, *Gbla*, *Yaa*), negatives (*… we*, *Ko …*), and accent marks (*Ní*, *níhi*, *nɔ́*, *Ná*). They follow patterns seen on JW.ORG, but each sentence was assembled by the translator.
